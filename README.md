# Building In Public

## Development Learning Journey

Welcome to my **Software Development and AI learning journey**.

This repository documents my day-by-day progress in learning software development, web development, artificial intelligence, machine learning, and related technologies through consistent practice and hands-on implementation.

Rather than simply collecting code, I aim to document what I learn, how things work, and how I apply my knowledge through exercises, experiments, and mini-projects.

### 🎯 Objectives

* Build strong programming and software development fundamentals.
* Learn web development, AI, and machine learning through practical implementation.
* Maintain organized notes documenting concepts, code, and key learnings.
* Strengthen understanding through exercises, experiments, and mini-projects.
* Track daily progress and develop a consistent learning habit.

### 📂 Repository Structure

The repository follows a chronological, day-wise structure, with a new folder added for every day of learning. The internal structure of each folder depends on the topics studied and the work completed that day.

```text
Development-Learning-Journey/
│
├── Day-001/
│   ├── notes.md
│   ├── concepts/
│   ├── exercises/
│   └── mini-project/
│
├── Day-002/
│   ├── notes.md
│   └── ...
│
├── Day-003/
│   └── ...
│
└── README.md
```

*The folder structure is flexible and will evolve with my learning.*

### 📝 What Each Day May Include

* **Concepts & Notes** — Markdown documentation of topics learned and their underlying mechanisms.
* **Code Implementations** — Practical code written while learning new concepts and technologies.
* **Exercises** — Hands-on problems to reinforce understanding.
* **Experiments** — Small implementations to explore ideas and test concepts.
* **Mini-Projects** — Small, practical applications built to apply newly acquired skills.

### 📈 My Commitment

This repository will grow **one day at a time**, creating a continuous record of my learning, practice, experiments, and progress.

The focus is not just on learning how to use tools and frameworks, but on understanding the fundamentals behind them and applying that knowledge through code.

Major projects will be maintained in separate repositories to keep their development, documentation, and implementations independent.

### 🚀 Long-Term Vision

To develop strong foundations in software engineering, become proficient in modern web development and AI/ML, and gradually build the skills required to develop practical, production-oriented applications.

**Learn by understanding. Improve by building. Progress every day.**
